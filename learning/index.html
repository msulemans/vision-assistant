    PRESERVED FAILURE

    Timeout was called “cancel”

    The first live attempt waited 180 seconds. The adapter merged selector timeout with Escape. It now emits selection_timed_out; a regression test protects the distinction.

    What PNG-only means in this milestone

    Trusted code validates chunk lengths and CRCs, declared dimensions, colour and bit depth, bounded decompression, row filters, and final IEND. It rejects animation, interlacing, unknown critical chunks, oversized input, symlinks, and non-PNG data. JPEG/HEIC conversion and pixel resizing are not silently delegated to a global package.

    Extension, measured: M018 browser computer-use agent — a disposable loopback browser, typed fail-closed guards, 50 frozen tasks with independent oracles, and one-shot benchmarks. Screenshot-only result: 4/30 development and 3/18 held-out productive (Wilson 0.06–0.39), refusals 1/2 expected-safe, zero forbidden actions; the proposed gate was not met and is preserved as-is. The target-assisted treatment (opaque target ids resolved by trusted code — clicks by id instead of pixels) was planned after the measured failure class, frozen before any code, and evaluated once on a fresh 20-task set with a paired baseline: 1/18 → 6/18 productive (Wilson 0.16–0.56; five genuine flips, one trivially-satisfied task annotated), refusals 0/2 with one fixture-local submission attempt recorded, zero forbidden actions. The live Hacker News pilot then ran once under a frozen protocol: the model had the complete front page in one screenshot, clicked a non-navigating link twice, and produced no answer — a failed run recorded as-is. The typed treatment (M019) then froze capability modes the model cannot escape, a ui: namespace keeping control references out of answer data, and semantic form operations with trusted read-back; its scripted gate passed with zero model calls, its development gate met criteria at 4/5, and the frozen 20-task evaluation ran once — 10/18 productive (answer 5/5, navigation 5/6, form 0/7: correct actions refused for extra fields), refusals 2/2 safe-blocked, zero forbidden actions; the 15/18 gate was not met and the result stands. The measured boundaries are the results — benchmark · treatment evaluation · typed evaluation.

    05 / Practice

    Explain it before advancing

    Knowing the command is not the same as knowing the system. Search the glossary, flip the cards, then test the trust boundary.

    Field glossary

    Artifact
    A private normalized image used inside one turn.
    CRC
    A PNG chunk checksum that detects damaged bytes.
    Ephemeral
    Exists only while needed, with deletion tested.
    Inference
    A plausible conclusion not directly visible in pixels.
    Model projector
    The component that converts image features for the language model.
    Grounding
    Connecting an answer or target to evidence actually present on screen.
    Accessibility tree
    Trusted UI roles, names, states, and element identities exposed by macOS.
    Stale observation
    A screenshot that no longer matches the screen where an action would occur.

          M005 v4: the user-reported Qwen run scored 23/24, with 3.792 GiB sampled RSS at context size 4096. The harness now honors the documented 0.95 pass rate. Qwen3.5-4B is the selected Phase-1 configuration; cold-readiness and cancellation certification trials remain open for packaging.

          M006 live: the one-shot assistant answered in ~0.7 s to first token and released its artifact; an interrupt during model load cancelled cleanly with nothing left behind. The stop check deliberately surfaced a real bug — a leaked artifact and an unhandled traceback — now protected by regression tests.

          M007 held-out: baseline reproduced 23/24, and the OCR-augmented prompts scored 24/24 — the missed dialog string is read reliably after a zoom. Facts reach the model prompt only; traces keep counts, never text.

          M008 chat: one session, one capture — six frozen tasks (three reference, three corrections) passed 6/6 with every artifact released and prompts under 333 characters.

          M009 UI: a loopback-only page captures, redacts, and answers on the pinned model — all five read-only capstones passed live, including stop with no orphaned process and an empty artifact root. Two real bugs the run surfaced (large-image context overflow, stop during model load) are fixed and regression-tested.

          M010 proposals: the model may propose, but seven strict schemas and a consequence policy dispose — secret targets and scope escapes are denied, and 13/13 adversarial payloads were contained live with zero bypasses. A test proves no executor exists anywhere in the project.

          M011 loop: observe → propose → validate → approve → fake-execute → verify ran all three frozen tasks in one step each with zero host input events. The first attempt blocked everything — the model would not emit JSON — and the fix was to constrain decoding with a runtime JSON schema, not to ask more politely.

          M012 grounding: read-only Accessibility roles, names, and identifiers resolve to stable element identities whose screenshot regions OCR confirms at 1× and 2×. The live run caught a real substring false positive — "AC" matched "Subtract" mid-word — now fixed and frozen as a regression task; the opt-in permission shows its denial path honestly.

          M013 executor: the first host actions — a click is an identity-addressed AXPress, typing is an accessibility value write that is read back, and key events require the target app to be frontmost. Every refusal path (unknown element, coordinates, secrets, declined, stale frame, cancellation) was demonstrated live with nothing posted.

          M014 bounded agent: each task is one frozen goal pursued as separately confirmed steps under hard budgets. The deterministic gate runs 22 adversarial scenarios; live demos show a stale-frame recovery re-planning at the new position, an unexpected dialog and a revoked permission both stopping with zero actions, an external state change read as user takeover, and adversarial screen text flagged — and never followed.

          M015 packaging: the same code installs from a self-contained bundle with a frozen offline audit — outbound network clients live only in the model downloader (explicit, one-time) and the loopback calls to the local server; the installer and doctor touch no network at all. The smoke gate runs the read-only profile end-to-end (44/44 grounding plus a verified model ask) even when every non-loopback network route is denied, and uninstall removes code while deleting models or captures only when explicitly asked.

          M016 field manual: one real recorded turn anchors measurement — 1546 of 1547 ms is the model stage. Twelve failures, two of them open limitations, are browsable with causes and evidence; the failure that produced each guard stays on the record. Five teach-back tasks check understanding against the gate, and the fixture-adding procedure is demonstrated end-to-end.

          M017 hardening: the audit proves the claims with canaries, re-runs, and rebuilds — 26 checks across eleven areas, zero critical. Two bundles build byte-identically; the release manifest is byte-stable; rollback and removal are re-verified on real installs; and the remaining limitations (unsigned artifacts, Electron trees, size-mode verification) stay on the record. The roadmap ends here, evidenced end to end.
