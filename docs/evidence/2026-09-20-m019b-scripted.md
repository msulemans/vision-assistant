## Environment findings and fixes (recorded)

1. **Console precheck**: `IOConsoleLocked = No`. Lesson: the ioreg key is
   always present — check its *value*, not its presence.
2. **First run failed 2/6** (`runs/m019/scripted.json`):
   - *navigate*: the click executed but the page never navigated. Repeated
     runs plus new `key`/`active` diagnostics showed the helper window at
     `key=false, active=false`: **macOS 14 cooperative activation refuses to
     activate a background-spawned helper**, and in that state synthesized
     NSEvent clicks are swallowed (they worked in earlier user-attended
     runs, and mid-session in some runs, but are not deterministic).
   - *moving-target*: timing race — the fixture's 1 s layout shift fired
     before the typed observation, so no move could be detected.
3. **Fixes (all additive, frozen paths untouched):**
   - helper: optional `"method":"dom"` on `click_target` — identical guards
     (stale/hidden/disabled/moved/offscreen) then DOM activation
     (`el.click()`); without the field the frozen NSEvent path is unchanged.
     `ensureActive()` before synthesized events, plus `key`/`active`
     diagnostics on click/state replies.
   - M019 typed `click_target`/`save_form` use `method="dom"` (semantic
     activation, consistent with `fill`/`set_control`); the M018 screenshot
     and target modes keep events (pinned by invariant tests).
   - harness warm-up: click "Search" until the URL lands on `/search/`
     (absorbing any activation click), recorded in the report.
   - moving-target scenario redesigned as stale-then-recover; the live moved
     refusal runs as a trusted probe using the proven M018T mechanics
     (observe → wait 1.6 s → click → `refused_target_moved`).
4. Runs 4–5 (after fixes): 6/6 PASS, twice in a row.

## What this does and does not prove

Proves: the M019 contracts (modes, capability manifests, `ui:` namespace,
semantic operations with read-back, authorized-save-only, credential/
submission denials, no-repeat, structured answers) integrate deterministically
through the real loop, helper, and fixtures. Does not load or test the model —
that is M019C, which requires an explicit go-ahead.
