## Bugs found by the run, fixed and regression-tested

1. **Context overflow on large captures** (`2fddb3c`): a 1800×2400 image
   exceeded the pinned 4096-token context (llama-server: "4252 tokens > 4096").
   The model view is now bounded — `pixels.fit_for_model` downscales captures
   above 3,000,000 pixels for the model call only; artifacts and OCR evidence
   stay full-resolution; traces record `image_scaled`.
2. **Stop during model load** (`2972c7c`): `adapter.start()` now notices an
   external `stop()` mid-load and aborts promptly instead of waiting for the
   health-check deadline.

Both findings came from real UI use — exactly what the capstone gate is for.
