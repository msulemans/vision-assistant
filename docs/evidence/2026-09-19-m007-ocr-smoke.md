# M007 OCR smoke + pipeline freeze (2026-09-19)

First real run of the M007 augmentation path on the frozen difficult subset:
`tools/vision_ocr.swift` (macOS Vision `VNRecognizeTextRequest`, literal mode)
compiled with `swiftc -O` in ~5 s, plus `pixels.py` integer zoom.

## Commands

```bash
swiftc -O tools/vision_ocr.swift -o runs/m007-tools/vision_ocr
runs/m007-tools/vision_ocr runs/m004-corpus/dialog/m004-dialog-14.png
runs/m007-tools/vision_ocr runs/m004-corpus/dialog/m004-dialog-14.png --correction
# x2/x4 variants produced with pixels.zoom_png, then OCR'd the same way
```

## Frozen decision

- Pipeline: **zoom ×2 (stdlib) → literal OCR → facts into the model prompt**.
  ×4 regressed; language correction adds risk of inventing words, so literal
  stays the default (the `--correction` flag exists for experiments only).
- The synthetic block font is a worst case for Vision; real screenshots with
  system fonts should read better. The gate is scored on the model's final
  answers, not OCR exactness — OCR text is additional evidence, never a trace
  entry.
- Guard rules unchanged: `m004-small_text-13..15` must not regress; full
  held-out stays ≥ 0.95 with unsupported 0 and forbidden 0.
